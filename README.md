# Fourier Analysis and Signal Modulation System

MATLAB DSP experiment covering pulse-width spectra, convolution theorem verification, synthetic speech-band AM modulation, coherent demodulation, reconstruction error, and exported figures. An Octave-compatible regression script uses no toolbox functions.

## Run

Run `main` in MATLAB or `octave --no-gui main.m`. Outputs are written under output/. Supply your own audio by replacing the synthetic message source; the checked demo is deterministic.
